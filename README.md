# 🧩 Exercícios de JavaScript e DOM

Oito mini-aplicações em **HTML e JavaScript puro** (sem bibliotecas) para praticar manipulação do DOM, eventos e lógica condicional.

**👉 [Abrir online](https://oimanum.github.io/emanuelly-maciel-lista02/)**

| Exercício | O que pratica |
| --- | --- |
| [Contador de cliques](contador/contador.html) | Eventos e atualização de texto na página |
| [Tabuada](tabuada/tabuada.html) | Laços e geração de conteúdo |
| [Modo claro/escuro](tema/tema.html) | Troca de estilos por JavaScript |
| [Destacar](destacar/destacar.html) | Percorrer elementos e aplicar estilo ao encontrar o nome digitado |
| [Filtrar](filtrar/filtrar.html) | Filtro de lista em tempo real (`oninput`) |
| [Confirme sua presença](presenca/presenca.html) | Caixas de seleção em uma lista |
| [Sistema de multas](multas/index.html) | Condicionais e leitura de campos |
| [Verificador de idade](verificadorIdade/verificadorIdade.html) | Cálculo com datas, condicionais e troca de imagem |

## Como rodar

Não precisa instalar nada: abra o `index.html` no navegador.

## Tecnologias

`HTML5` · `CSS3` · `JavaScript` · `DOM`
